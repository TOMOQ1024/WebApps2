## はじめに

こんにちは！このサイトにブログ機能を追加しました．  
このブログでは，技術的なことから日常のことまで，いろいろなことを書いていこうと思います．

## 技術スタック

このブログは以下の技術で作られています：

- **Next.js** - React フレームワーク
- **MDX** - Markdown + JSX
- **next-mdx-remote** - 動的 MDX レンダリング

## コード例

コードブロックも書けます：

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

インラインコードも `console.log("Hello!")` のように書けます．

## 数式

LaTeX 記法で数式も書けます．

インライン数式：オイラーの等式 $e^{i\pi} + 1 = 0$ は美しいですね．

ディスプレイ数式：

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

二次方程式の解の公式：

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
