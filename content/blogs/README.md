# content/blogs/

このディレクトリの MDX ファイルは **現在サイトでは使用されていません**．

ブログ記事は Supabase の `articles` テーブルで管理され，以下から投稿・編集できます．

- 一覧: `/blogs`
- 投稿: `/blogs/new`
- 管理: `/blogs/manage`

## このディレクトリに残っているファイルについて

`hello-world.mdx` や `draft.mdx` などは，以前のファイルベース運用の名残です．参照用のアーカイブとして残していますが，アプリからは読み込まれません．

既存の MDX を公開したい場合は，`/blogs/new` から内容を移行するか，DB に直接登録してください．
