# Graph 3D

3 次元グラフを描画するページ．

リンク: [https://www.tomoq.net/apps/graph-3d](https://www.tomoq.net/apps/graph-3d)

## 対応形式

### 陽関数 (exp)

`z=` で始まり，右辺に `z` を含まない式は陽関数として解釈される．

例：`z=\sin(x)\cos(y)` → z = sin(x)cos(y) の曲面を描画

### 陰関数 (imp)

以下のいずれかに該当する式は陰関数として解釈される：
- `z=` で始まり，右辺に `z` を含む式
- `z` を変数として含む式（`z=` で始まらない）

Marching Cubes アルゴリズムで等値面（f(x, y, z) = 0）を描画する．

以下の形式に対応（`=`, `<`, `>`, `<=`, `>=` のいずれかが必須）：
- `x^2+y^2+z^2=4` → x² + y² + z² - 4 = 0 として評価（左辺 - 右辺）
- `z=\sqrt{4-x^2-y^2-z^2}` → z - √(4-x²-y²-z²) = 0 として評価
- `x^2+y^2+z^2<4` → 不等式として評価（境界面のみ描画）

例：`x^2+y^2+z^2=4` → 半径 2 の球面を描画

#### 描画モード

関係演算子によって描画面が切り替わる：

- **等式** (`=`): 両面描画（DoubleSide）
- **less** (`<`, `<=`, `\le`, `\leq`): 正側の面のみ（FrontSide）
- **greater** (`>`, `>=`, `\ge`, `\geq`): 裏側の面のみ（BackSide）

## 操作方法(共通)

- 左下のフォームで数式を設定する(入力例は[こちら](#入力ガイド))
- グリッドアイコンのボタンでワイヤーフレーム表示を切り替える
- 家アイコンのボタンでカメラ位置をリセットする
- リンクアイコンのボタンで共有用 URL をクリップボードにコピーする

## 操作方法(PC)

- キャンバス上でのマウスドラッグで回転
- キャンバス上でのスクロールでズームイン・アウト
- 右クリックドラッグでパン

## 操作方法(スマホ)

- キャンバス上での 1 本指ドラッグで回転
- キャンバス上でのピンチでズームイン・アウト
- 2 本指ドラッグでパン

## 入力ガイド

数式で使用できる入力は以下の通り．

### 基本的な変数と定数

- `x` - 横軸変数
- `y` - 奥行き変数
- `z` - 鉛直軸変数（陰関数モードで使用）
- `\pi` または `π` - 円周率
- `e` - 自然対数の底

### 基本演算

- `+`, `-`, `*`, `/` - 四則演算
- `^` - べき乗
- `|x|` - 絶対値

### 関数

- `sin`, `cos`, `tan`, `cot`, `sec`, `csc` - 三角関数
- `sinh`, `cosh`, `tanh`, `coth`, `sech`, `csch` - 双曲線関数
- `exp` - 指数関数
- `ln` - 自然対数関数
- `sqrt` - 平方根
- `max`, `min` - 最大・最小

### 入力例（陽関数 exp）

- `z=\sin(x)\cos(y)` - 正弦と余弦の積
- `z=x^2+y^2` - 放物面
- `z=\sin(\sqrt{x^2+y^2})` - 波紋状の曲面
- `z=\exp(-(x^2+y^2))` - ガウス曲面

### 入力例（陰関数 imp）

等式（両面描画）：
- `x^2+y^2+z^2=4` - 球面（半径 2）
- `x^2+y^2-z^2=1` - 双曲面
- `x^2+z^2=1` - 円柱
- `\sin(x)+\sin(y)+\sin(z)=0` - ジャイロイド的な曲面

不等式（片面描画）：
- `x^2+y^2+z^2<4` - 球の内部（FrontSide）
- `x^2+y^2+z^2>4` - 球の外部（BackSide）
