# Linear Attractor 2D

複数のアフィン変換による 2 次元アトラクターを観察できるページ

## 機能

- GPGPUによる高速計算（最大65536点）
- 4つのアフィン変換行列とその重み設定
- マウスドラッグでパン
- マウスホイールでズーム
- サンプルパラメータ（Sierpinski Triangle, Barnsley Fern, Dragon Curveなど）

## 操作方法

- **マウスドラッグ**: カメラパン
- **マウスホイール**: ズーム
- **カメラリセットボタン**: カメラ位置とズームをリセット
- **設定リセットボタン**: パラメータを初期値に戻す
- **原点初期化ボタン**: 点群を原点に戻す
- **ランダムサンプルボタン**: ランダムなサンプルパラメータを適用
